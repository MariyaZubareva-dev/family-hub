# Календарь

Оформление следует interface-style.md. Сетка месяца — семь колонок, компактные ячейки с отметками планов. Навигация: предыдущий/следующий месяц, «Сегодня», выбор дня и «Весь месяц». Выбранный день и текущая дата различаются; даты — кнопки, доступные с клавиатуры.

Список показывает запланированные события и напоминания выбранного месяца или дня. Названия переносятся, длинные описания раскрываются отдельно. Указаны тип, время и ответственный. Пустое состояние и загрузка не смешиваются.

Событие и напоминание создаются через общий Modal из Финансов. Поля даты и времени разделены, чтобы помещаться на телефоне. Событие длится один час, участники — все члены семьи, как в предыдущей реализации. Пояснение доступно через кнопку «О календаре». Часовой пояс соответствует устройству, даты отправляются в API как ISO UTC. После сохранения открывается день созданного плана и показывается подтверждение. Во время отправки повторное сохранение и закрытие отключены; при ошибке введённые данные сохраняются.

API событий, напоминаний и семьи не меняется. Изменения ограничены frontend; миграции и пересборка backend не нужны. Проверяются создание и повторная загрузка обоих типов планов, выбор дат/месяца, сохранение черновика при ошибке, возврат фокуса, ширины 320/393/768 px и короткий экран 320×480.
