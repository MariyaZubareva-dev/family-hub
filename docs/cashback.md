# Кешбэк банков

Единица учёта: семья + автор + нормализованное название банка + месяц YYYY-MM. Карты не создаются. Автор назначается сервером; администратор при редактировании не меняет владельца. Названия Т-Банк/Тинькофф, Альфа/Альфа-Банк и Сбер/Сбербанк объединяются у одного владельца. Предложения разных участников независимы.

## API

- GET `/api/v1/finance/cashback-banks?month=YYYY-MM`: записи выбранного месяца, авторы и `can_edit`. По умолчанию месяц определяется по часовому поясу семьи. `meta` содержит month, today и user_id.
- POST того же адреса: bank_name, month, entries. Для обновления существующего банка нужны текущая revision и полный проверенный список. Другой месяц сохраняется отдельно.
- PATCH `/{id}`: те же поля с revision, владелец и месяц не меняются.
- DELETE `/{id}`: revision в JSON. Удаление мягкое; повторное создание восстанавливает запись с новой revision. Конкурирующая или устаревшая запись получает 409.
- POST `/recognize`: один image_data (PNG/JPEG/WebP, до 5 МБ и 16 мегапикселей). Возвращает редактируемый черновик, не сохраняет изображение или категории. Ограничение — 12 запросов в минуту на пользователя. Клиент отправляет до 5 скриншотов одного банка последовательно.

Категория: category, rate (0 < % <= 100), reward_unit (RUB/POINTS/MILES), active, cap_amount (лимит вознаграждения, не остаток), notes, valid_from/valid_to (необязательные даты внутри месяца). Повторяющиеся названия категорий отклоняются. Неизвестный тип OCR `UNKNOWN` должен быть уточнён перед сохранением.

Все операции доступны только с доступом к разделу «Финансы». Просмотр общий для семьи; изменение и удаление — автору или администратору. Межсемейные идентификаторы возвращают 404. Чужие авторы из запроса игнорируются. Изображения не хранятся в БД; временный файл удаляется после OCR. Tesseract работает без дополнительного API; существующая настройка OPENAI_API_KEY включает дополнительный анализ изображения, как у чеков. Отказ провайдера оставляет локальный результат.

## Интерфейс и рекомендации

«Финансы → Кешбэк»: месяц, владельцы, банк, поиск по категории/банку/имени; сводная таблица на широком экране и компактные строки на телефоне. Импорт объединяет новые категории с сохранёнными по названию; совпавшая категория берётся из нового черновика и требует повторной проверки. Разные распознанные банки в одной загрузке не смешиваются. Данные сохраняются только после проверки пользователем. Активность каждой распознанной категории по умолчанию false; её подтверждает пользователь.

На главной после бюджета — до четырёх лучших ставок в рублях за текущий месяц, с банком и владельцем, переключением «Мои банки / Вся семья» и загрузкой скриншотов сразу в редактор. Будущие, истёкшие, неактивные категории и нулевой лимит исключаются. Баллы и мили остаются в полном списке и не сравниваются с рублями. При равенстве ставок выбирается стабильный представитель; остальные видны в полном списке.

Рекомендация сравнивает ставки, не гарантирует начисление. Остаток лимита неизвестен. Оригинальное название категории банка сохраняется; категория товара в чеке не определяет MCC продавца. Импорт не создаёт расходов или доходов.
