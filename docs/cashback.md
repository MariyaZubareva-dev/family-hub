# Кешбэк банков

Единица учёта: семья + автор + нормализованное название банка + месяц YYYY-MM. Карты не создаются. Автор назначается сервером; администратор при редактировании не меняет владельца. Банки выбираются из справочника `backend/config/cashback_banks.php`. Он содержит 25 банков с единым названием для интерфейса, официальным сокращённым наименованием и вариантами написания. Названия Ozon/Озон/Ozon Банк, Яндекс/Яндекс Банк, Т-Банк/Тинькофф и другие известные варианты объединяются у одного владельца. Предложения разных участников независимы.

## API

- GET `/api/v1/finance/cashback-banks?month=YYYY-MM`: записи выбранного месяца, авторы и `can_edit`. По умолчанию месяц определяется по часовому поясу семьи. `meta` содержит month, today, user_id и banks — справочник для выпадающего списка.
- POST того же адреса: bank_name, month, entries. Для обновления существующего банка нужны текущая revision и полный проверенный список. Другой месяц сохраняется отдельно.
- PATCH `/{id}`: те же поля с revision, владелец и месяц не меняются.
- DELETE `/{id}`: revision в JSON. Удаление мягкое; повторное создание восстанавливает запись с новой revision. Конкурирующая или устаревшая запись получает 409.
- POST `/recognize`: один image_data (PNG/JPEG/WebP, до 5 МБ и 16 мегапикселей). Возвращает редактируемый черновик, не сохраняет изображение или категории. Ограничение — 12 запросов в минуту на пользователя. Клиент отправляет до 5 скриншотов одного банка последовательно.

Категория: category, rate (0 < % <= 100), reward_unit (RUB/POINTS/MILES), active, cap_amount (лимит вознаграждения, не остаток), notes, valid_from/valid_to (необязательные даты внутри месяца). Повторяющиеся названия категорий отклоняются. Если OCR не определил тип вознаграждения, по умолчанию выбираются рубли. Явно распознанные баллы и мили сохраняются. Пользователь может изменить тип перед сохранением. В одной записи допускается до 300 категорий; повторные скриншоты объединяются по названию категории.

Все операции доступны только с доступом к разделу «Финансы». Просмотр общий для семьи; изменение и удаление — автору или администратору. Межсемейные идентификаторы возвращают 404. Чужие авторы из запроса игнорируются. Изображения не хранятся в БД; временный файл удаляется после OCR. Tesseract работает без дополнительного API; существующая настройка OPENAI_API_KEY включает дополнительный анализ изображения, как у чеков. Отказ провайдера оставляет локальный результат.

## Интерфейс и рекомендации

«Финансы → Кешбэк»: месяц, владельцы, банк, поиск по категории/банку/имени. В полном разделе и сводке на главной — компактная таблица из трёх колонок: категория с банком под ней, процент кешбэка, владелец. Шрифт 10–12 px, строки разделены тонкими линиями. Нажатие на категорию в полном списке открывает условия и доступное автору/администратору редактирование банка. На главной нажатие ведёт в полный раздел. По умолчанию отображаются действующие категории текущего месяца, переключатель «Все» открывает также неактивные и истёкшие предложения. Для архивного или будущего месяца режим называется «Выбранные» и показывает выбранные категории периода, не помечая их действующими сегодня. Баллы и мили явно подписаны и не получают отметку лучшей рублёвой ставки. Импорт объединяет новые категории с сохранёнными по названию; совпавшая категория берётся из нового черновика и требует повторной проверки. Разные распознанные банки в одной загрузке не смешиваются. Данные сохраняются только после проверки пользователем. Распознанные категории по умолчанию отмечены как выбранные в банке. Перед сохранением пользователь проверяет данные; для неактивных предложений отметку нужно снять. Во время распознавания вверху окна виден индикатор с номером скриншота, поля и сохранение заблокированы.

На главной после бюджета — все уникальные действующие категории за текущий месяц без ограничения количества, с банком и владельцем, переключением «Мои банки / Вся семья». При совпадении названий остаётся максимальный процент. Начальный порядок категорий алфавитный. Нажатие на заголовок «Кешбэк» в обеих таблицах сортирует проценты по убыванию, повторное — по возрастанию. Сортировка числовая, включая дробные ставки. Баллы и мили подписаны и не конвертируются в рубли; выбор по проценту не означает равенства денежной выгоды разных программ. Будущие, истёкшие, неактивные категории и нулевой лимит исключаются. При равенстве ставок выбирается стабильный представитель; остальные видны в полном списке. Загрузка категорий доступна только в «Финансы → Кешбэк».

Рекомендация сравнивает ставки, не гарантирует начисление. Остаток лимита неизвестен. Оригинальное название категории банка сохраняется; категория товара в чеке не определяет MCC продавца. Импорт не создаёт расходов или доходов.

## Нормализация сохранённых записей

Миграция `2026_10_23_000031_normalize_cashback_bank_names` исправляет известные варианты названий во всех месяцах. Объединение выполняется только внутри одной семьи, владельца и месяца. Сохраняются все различные категории; при конфликте условий одной категории используется последняя отредактированная запись. Удалённые предложения не возвращаются в действующий список. Исходные строки сохраняются в `cashback_bank_normalization_backups` до изменения и не доступны через пользовательский API. Повторный запуск не меняет уже исправленные записи.

Неизвестные названия не угадываются и не объединяются. Они остаются доступными для редактирования существующих категорий и выводятся в отчёте `unknown`. Новую запись можно создать только с банком из справочника.

Аудит без изменения данных: `php artisan family:normalize-cashback-banks`. Применение с резервными копиями: `php artisan family:normalize-cashback-banks --apply`. Команда возвращает числа переименований и объединений и список неизвестных названий. Откат миграции не перезаписывает последующие изменения пользователей; исходные снимки сохраняются для адресного восстановления.

Справочник проверен 23.10.2026 по [реестру Банка России](https://www.cbr.ru/registries/nps/reestr/) и [списку кредитных организаций](https://www.cbr.ru/banking_sector/credit/FullCoList/). Это список поддерживаемых банков, а не полный реестр банков России. Для расширения добавьте проверенное наименование и точные варианты в конфигурацию.
