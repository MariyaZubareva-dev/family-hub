# Финансовая модель Family Hub

Функциональность перенесена из шести предоставленных таблиц.

## 1. Ежедневные траты

Исходная таблица рассчитывает бюджет на день как остаток после обязательных расходов и заданной доли накоплений, делённый на количество дней месяца. Накопительный лимит на конкретную дату ведётся кумулятивно: допустимая сумма к дате минус фактические траты.

В Family Hub это представлено как:

`daily_limit = (monthly_income - fixed - future - monthly_savings) / days_in_month`

`safe_to_spend = max(0, daily_limit × day_of_month - actual_flexible_expenses_current_month)`

## 2. Метод «Единственное важное число»

`monthly_income = Σ income`

`fixed = Σ expenses with type FIXED`

`future = Σ expenses with type FUTURE`

`flexible = Σ expenses with type FLEXIBLE`

`maneuver = monthly_income - fixed - future - flexible`

`single_important_number = flexible / 4.3`

Коэффициент 4,3 — среднее количество недель в месяце, использованное в исходном планировщике.

## 3. Годовой бюджет

Исходный планировщик даёт 12 месяцев × набор категорий и считает суммы по месяцам и за год. В приложении реализована редактируемая матрица категорий и месяцев с автоматическими итогами.

Категории перенесены из исходного шаблона: жильё, повседневные расходы, транспорт, развлечения, здоровье, путешествия, отдых и восстановление, подписки, личное, финансы.

## 4. Подушка безопасности

`target = monthly_budget × target_months`

`remaining = max(0, target - saved)`

`months_to_goal = remaining / monthly_saving`

`required_monthly_saving = remaining / target_months_for_plan`

В исходной методике диапазон цели — 3–6 месячных бюджетов.

## 5. Крупные расходы

Для каждой нерегулярной цели: стоимость, периодичность и классификация «необходимость / пожелание».

`monthly_set_aside = cost / period_months`

Итоги рассчитываются отдельно по двум категориям и в сумме.

## 6. Кредит

Для аннуитетного кредита:

`r = annual_rate / 12 / 100`

`n = years × 12`

`payment = P × r / (1 - (1+r)^(-n))`

Досрочное погашение моделируется помесячно. Поддерживаются два режима: сокращение срока и уменьшение платежа. Для каждого сценария считается срок, начисленные проценты, остаток долга и первые 12 периодов графика.
