# Покупки

Экран следует принятому стилю из interface-style.md. Крупные покупки и подарки, регулярные покупки — отдельные вкладки. Обе формы открываются в общем компоненте Modal из Финансов: ширина до 420 px, сгруппированные поля, исходные размеры шрифта и кнопок.

Категория выбирается из списка. Первый пункт — «＋ Добавить новую категорию». Он открывает поле внутри текущего окна, сохраняя черновик покупки. После сохранения категория автоматически выбрана. Отмена категории не закрывает покупку. Пока категория создаётся, сохранение покупки недоступно. Ошибка сохраняет введённые данные.

Справочник общий с «Финансы → Категории»: в покупках доступны только активные категории расходов своей семьи. Чтение доступно участнику с видимостью «Покупки», создание — администратору, по правилам Финансов. Категории доходов не показываются. Новая категория сохраняется на сервере сразу, даже если затем отменить покупку. Дубли с разным регистром отклоняются с понятным сообщением.

API:
- GET /api/v1/planned-purchases/categories → data: [{id, name}].
- POST /api/v1/planned-purchases/categories, {name}: обязательное название до 80 символов; возвращает data: {id, name}, 201 для новой, 422 для дубликата.
- Контракт покупок сохранён: category — строка; estimated_amount — число; регулярная покупка требует due_date и cadence_months (1–120).
- «Купили» вызывает существующий POST /planned-purchases/{id}/purchased, обновляет следующую дату и показывает результат.

Миграция 2026_10_21_000023 создаёт purchase_categories и переносит существующие названия из planned_purchases. Миграция 2026_10_21_000024 переносит отдельные категории покупок в справочник расходов без дубликатов. Сами покупки не изменяются. Финансы и Семья используют прежние стили.

Обновление production: собрать backend и frontend с прежним ALPINE_MIRROR, пересоздать backend, выполнить php artisan migrate --force, затем пересоздать backend-nginx и frontend. nginx обновляется после backend для повторного разрешения адреса контейнера. Queue и scheduler не менялись; их пересборка для этого изменения не требуется.
